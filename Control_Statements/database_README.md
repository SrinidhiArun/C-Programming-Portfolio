# Database

## Overview

A C programming exercise demonstrating the concepts implemented in `database.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Pointers
- While Loops

## Source File

- `database.c`

## Compilation

```bash
gcc database.c -o database
```

## Execution

```bash
./database
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
