# Calc

## Overview

A C programming exercise demonstrating the concepts implemented in `calc.c`.

## Concepts Demonstrated

- Bitwise Operations
- Character Handling
- Conditional Statements
- Functions
- Input / Output
- Pointers

## Source File

- `calc.c`

## Compilation

```bash
gcc calc.c -o calc
```

## Execution

```bash
./calc
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
