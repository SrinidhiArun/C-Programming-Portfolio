# Prime Number

## Overview

Determines whether a number is prime by checking its possible divisors.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- For Loops
- Functions
- Input / Output
- Number Theory
- Pointers

## Source File

- `prime.c`

## Compilation

```bash
gcc prime.c -o prime
```

## Execution

```bash
./prime
```

## Learning Objective

Practice conditional logic, loops, and basic number-theory problem solving.
