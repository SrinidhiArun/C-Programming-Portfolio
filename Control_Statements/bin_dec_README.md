# Bin Dec

## Overview

A C programming exercise demonstrating the concepts implemented in `bin_dec.c`.

## Concepts Demonstrated

- Bitwise Operations
- Functions
- Input / Output
- Pointers
- While Loops

## Source File

- `bin_dec.c`

## Compilation

```bash
gcc bin_dec.c -o bin_dec
```

## Execution

```bash
./bin_dec
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
