# Sum For Digits

## Overview

A C programming exercise demonstrating the concepts implemented in `sum_for_digits.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- For Loops
- Functions
- Input / Output
- Number Manipulation
- Pointers

## Source File

- `sum_for_digits.c`

## Compilation

```bash
gcc sum_for_digits.c -o sum_for_digits
```

## Execution

```bash
./sum_for_digits
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
