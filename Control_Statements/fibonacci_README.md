# Fibonacci Sequence

## Overview

Generates values from the Fibonacci sequence using C programming constructs.

## Concepts Demonstrated

- Bitwise Operations
- For Loops
- Functions
- Input / Output
- Iteration
- Pointers

## Source File

- `fibonacci.c`

## Compilation

```bash
gcc fibonacci.c -o fibonacci
```

## Execution

```bash
./fibonacci
```

## Learning Objective

Practice loops, arithmetic, and maintaining state across iterations.
