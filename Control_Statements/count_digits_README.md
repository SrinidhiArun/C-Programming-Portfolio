# Count Digits

## Overview

A C programming exercise demonstrating the concepts implemented in `count_digits.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Number Manipulation
- Pointers
- While Loops

## Source File

- `count_digits.c`

## Compilation

```bash
gcc count_digits.c -o count_digits
```

## Execution

```bash
./count_digits
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
