# Digits Sum

## Overview

A C programming exercise demonstrating the concepts implemented in `digits_sum.c`.

## Concepts Demonstrated

- Bitwise Operations
- Functions
- Input / Output
- Number Manipulation
- Pointers
- While Loops

## Source File

- `digits_sum.c`

## Compilation

```bash
gcc digits_sum.c -o digits_sum
```

## Execution

```bash
./digits_sum
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
