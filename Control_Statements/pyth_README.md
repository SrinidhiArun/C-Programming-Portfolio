# Pyth

## Overview

A C programming exercise demonstrating the concepts implemented in `pyth.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Pointers

## Source File

- `pyth.c`

## Compilation

```bash
gcc pyth.c -o pyth
```

## Execution

```bash
./pyth
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
