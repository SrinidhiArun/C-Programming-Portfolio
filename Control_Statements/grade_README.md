# Grade

## Overview

A C programming exercise demonstrating the concepts implemented in `grade.c`.

## Concepts Demonstrated

- Bitwise Operations
- Character Handling
- Conditional Statements
- Functions
- Input / Output
- Pointers

## Source File

- `grade.c`

## Compilation

```bash
gcc grade.c -o grade
```

## Execution

```bash
./grade
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
