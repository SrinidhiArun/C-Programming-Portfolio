# Sum Nums

## Overview

A C programming exercise demonstrating the concepts implemented in `sum_nums.c`.

## Concepts Demonstrated

- Bitwise Operations
- Do-While Loops
- Functions
- Input / Output
- Pointers
- While Loops

## Source File

- `sum_nums.c`

## Compilation

```bash
gcc sum_nums.c -o sum_nums
```

## Execution

```bash
./sum_nums
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
