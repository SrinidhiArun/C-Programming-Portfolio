# Digits Num

## Overview

A C programming exercise demonstrating the concepts implemented in `digits_num.c`.

## Concepts Demonstrated

- Bitwise Operations
- Do-While Loops
- Functions
- Input / Output
- Number Manipulation
- Pointers
- While Loops

## Source File

- `digits_num.c`

## Compilation

```bash
gcc digits_num.c -o digits_num
```

## Execution

```bash
./digits_num
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
