# Leap Year

## Overview

A C programming exercise demonstrating the concepts implemented in `leap_year.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Pointers

## Source File

## Compilation

```bash
gcc leap_year.c -o leap_year
```

## Execution

```bash
./leap_year
```

Strengthen C programming fundamentals through hands-on implementation and problem solving.
