# Switch

## Overview

A C programming exercise demonstrating the concepts implemented in `switch.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Pointers
- Switch Statements

## Source File

- `switch.c`

## Compilation

```bash
gcc switch.c -o switch
```

## Execution

```bash
./switch
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
