# Armstrong Number

## Overview

Checks whether a number satisfies the mathematical conditions of an Armstrong number.

## Concepts Demonstrated

- Conditional Statements
- For Loops
- Functions
- Input / Output
- Number Theory
- Pointers
- While Loops

## Source File

- `armstrong.c`

## Compilation

```bash
gcc armstrong.c -o armstrong
```

## Execution

```bash
./armstrong
```

## Learning Objective

Practice digit extraction, arithmetic operations, loops, and conditional logic.
