# Digits Count

## Overview

A C programming exercise demonstrating the concepts implemented in `digits_count.c`.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Number Manipulation
- Pointers
- While Loops

## Source File

- `digits_count.c`

## Compilation

```bash
gcc digits_count.c -o digits_count
```

## Execution

```bash
./digits_count
```

## Learning Objective

Strengthen C programming fundamentals through hands-on implementation and problem solving.
