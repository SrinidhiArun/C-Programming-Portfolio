# Factorial Calculation

## Overview

Calculates the factorial of a number using iterative or recursive logic.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Do-While Loops
- Functions
- Input / Output
- Iteration
- Pointers
- While Loops

## Source File

- `factorial.c`

## Compilation

```bash
gcc factorial.c -o factorial
```

## Execution

```bash
./factorial
```

## Learning Objective

Understand repeated multiplication and algorithmic iteration.
