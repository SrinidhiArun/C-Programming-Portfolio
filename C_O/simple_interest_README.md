# Simple Interest

## Overview

Calculates simple interest using principal, rate, and time.

## Concepts Demonstrated

- Bitwise Operations
- Functions
- Input / Output
- Pointers

## Source File

- `simple_interest.c`

## Compilation

```bash
gcc simple_interest.c -o simple_interest
```

## Execution

```bash
./simple_interest
```

## Learning Objective

Practice arithmetic operations, variables, and formatted input/output.
