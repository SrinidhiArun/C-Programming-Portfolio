# Ternary Operator

## Overview

Demonstrates conditional expressions using the C ternary operator.

## Concepts Demonstrated

- Bitwise Operations
- Conditional Statements
- Functions
- Input / Output
- Pointers

## Source File

- `ternary.c`

## Compilation

```bash
gcc ternary.c -o ternary
```

## Execution

```bash
./ternary
```

## Learning Objective

Practice concise conditional expressions in C.
