# Sizeof Operator

## Overview

Explores the sizeof operator and the memory requirements of C data types.

## Concepts Demonstrated

- Character Handling
- Functions
- Input / Output

## Source File

- `sizeof.c`

## Compilation

```bash
gcc sizeof.c -o sizeof
```

## Execution

```bash
./sizeof
```

## Learning Objective

Understand how C represents the size of different data types in memory.
