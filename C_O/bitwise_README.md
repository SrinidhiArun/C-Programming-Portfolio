# Bitwise Operations

## Overview

Demonstrates operations that manipulate individual bits within integer values.

## Concepts Demonstrated

- Bitwise Operations
- Pointers

## Source File

- `bitwise.c`

## Compilation

```bash
gcc bitwise.c -o bitwise
```

## Execution

```bash
./bitwise
```

## Learning Objective

Build an understanding of low-level bit manipulation used in systems and embedded programming.
