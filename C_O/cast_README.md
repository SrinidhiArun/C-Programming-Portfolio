# Type Casting

## Overview

Demonstrates conversion between different C data types.

## Concepts Demonstrated

- Bitwise Operations
- Functions
- Input / Output
- Pointers
- Type Casting

## Source File

- `cast.c`

## Compilation

```bash
gcc cast.c -o cast
```

## Execution

```bash
./cast
```

## Learning Objective

Understand implicit and explicit type conversion in C.
